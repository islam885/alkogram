# Alkogram: результат изменений

Реализованы 3 из 4 пунктов. Все три переключателя находятся в существующем экране Alkogram; новые настройки по умолчанию OFF, настройка секунд использует уже существующее значение.

## 1. Очистка EXIF / GPS

- `TMessagesProj/src/main/java/com/exteragram/messenger/utils/AlkogramPhotoPrivacy.java` — новая копия JPEG в кэше приложения, чтение ориентации через имеющийся AndroidX ExifInterface 1.3.6, поворот/отражение пикселей, новое кодирование JPEG без исходных EXIF/GPS/XMP/встроенных миниатюр. Исходный файл не записывается.
- `TMessagesProj/src/main/java/org/telegram/messenger/SendMessagesHelper.java` — обработка локальных фото до запуска album workers и обращения к кэшу отправленных файлов; отдельно обработка JPEG, отправляемых документами, включая URI и несколько документов. Идентификатор исходного пути заменяется путём очищенной копии, чтобы не переиспользовать ранее отправленный неочищенный документ.
- Ошибки чтения/декодирования/кодирования и нехватка памяти приводят к видимому сообщению и отмене, без отправки исходного JPEG. При ошибке предварительной обработки альбома альбом не запускается; в списке документов остальные документы могут быть отправлены отдельно.
- **Поддерживается только JPEG**, определяется по сигнатуре, а не только расширению. PNG/APNG, WebP, GIF, HEIC/HEIF, TIFF/RAW и видео не очищаются и могут отправляться штатно. Это явно написано рядом с переключателем. Не изменены пересылка уже размещённых на сервере документов и результаты удалённого поиска медиа.
- JPEG перекодируется с качеством 95: возможны изменения качества/цвета, большие изображения требуют памяти. Имена файлов не обезличиваются. Это очистка метаданных, а не скрытие информации, нарисованной на самом изображении. Очищенные файлы остаются в app-scoped кэше для штатной отправки/повтора, пока кэш не будет удалён.

## 2. Hide Stories — блокер исходников

В этой версии отсутствуют `StoriesController`, `DialogStoriesCell`, `StoryViewer`, соответствующие классы Stories и протокол `TL_stories*`. В `DialogsActivity.java` нет панели Stories. Не добавлен неработающий переключатель и не скрыты вместо историй unrelated подсказки/контакты. Для реализации нужен путь/ветка с настоящей панелью Stories. Исходники DialogsActivity не изменены.

## 3. Сохранение круглого видео

- `TMessagesProj/src/main/java/org/telegram/ui/ChatActivity.java` — отдельный пункт долгого нажатия «Сохранить в галерею как MP4» и отдельный обработчик.
- Используется штатный `FileLoader` для существующего файла и `MediaController.saveFile(..., type=1, ..., video/mp4, onSaved)` для экспорта в Movies/MediaStore, с существующей проверкой permissions на старых Android. Уведомление об успехе показывается только через callback успешного сохранения.
- Незагруженный/загружающийся файл: видимое сообщение «сначала загрузите», без автоматической загрузки и новых сетевых вызовов. После выдачи permission нужно повторить пункт меню.
- Прямые проверки `noforwards` сообщения, чата, мигрированного чата и известного исходного канала пересылки — независимо от имеющейся настройки обхода запретов. TTL, secret media, размытое/расширенное скрытое медиа, секретные чаты и запланированные сообщения исключены; проверки повторяются перед сохранением. Обычный кружочек уже является MP4; перекодирование видео не добавлено.

## 4. Секунды

- Использован существующий `ExteraConfig.formatTimeWithSeconds`, без второго preference или альтернативного форматтера.
- Новый пункт в Alkogram вызывает существующие `LocaleController.recreateFormatters()` и `parentLayout.rebuildAllFragmentViews(false, false)` для обновления экранов сообщений.
- Сохраняются существующие локализованные форматы 12/24 ч: `HH:mm:ss` либо `h:mm:ss a`; OFF возвращает прежний формат. Как и существующий переключатель в общих настройках, значение также влияет на остальные места, использующие `formatterDay`.

## Общие файлы

- `TMessagesProj/src/main/java/com/exteragram/messenger/ExteraConfig.java` — persistent prefs двух новых функций, OFF.
- `TMessagesProj/src/main/java/com/exteragram/messenger/preferences/AlkogramPrivacyPreferencesActivity.java` — три переключателя, пояснения и повторное использование существующей настройки секунд.
- `TMessagesProj/src/main/res/values/extera.xml` и `TMessagesProj/src/main/res/values-ru/extera.xml` — английские/русские строки.
- `Tools/check_alkogram_media.py` — повторяемые read-only статические проверки, запуск `python Tools/check_alkogram_media.py` из корня.

- Статические проверки prefs/UI, album/document fail-closed путей, защит сохранения, отсутствия загрузки в новом обработчике, существования ресурсов, Java delimiter balance: PASS. Это **не компиляция Java и не runtime-тест**.

## Не выполненные проверки на Android

После настройки JDK/SDK нужны сборка и проверки на устройстве: JPEG с GPS/моделью/датой и каждой EXIF orientation (сравнить hash оригинала), фото/документ/URI/альбом, ошибки и нехватка памяти, OFF и повторная отправка ранее отправленного файла; MP4 в MediaStore на Android 28 и 29+, отмена permission/экспорта, protected/TTL/незагруженные кружочки; переключение секунд, 12/24 ч, RU/EN, перезапуск. Runtime-результаты не заявляются.
